## Data Availability Statement

The processed daily station data used to train and evaluate the drought forecasting models, station metadata, curated manuscript table data, and figure-source CSV files are archived at Zenodo: https://doi.org/10.5281/zenodo.20583059. The processed station files include daily meteorological forcing, reference evapotranspiration, radiation variables, streamflow/runoff, and station metadata for eight Jinsha River Basin stations from 2010 to 2024. The custom 30-day and 90-day standardized water-balance drought indices and flash-drought early-risk labels are generated by the released code using training-period standardization to avoid temporal leakage. The corresponding author has confirmed that the processed station observations may be publicly redistributed; processed data and derived manuscript data are released under CC BY 4.0.

## Software Availability Statement

Version **1.0.0-wrr-submission** of the Python code used for data preprocessing, target construction, model training, baseline comparison, recursive forecasting, ablation summaries, and manuscript figure/table data generation is preserved at Zenodo: https://doi.org/10.5281/zenodo.20583059. The code is developed openly at https://github.com/ARETE-zzwl/jinsha-daily-drought-hybrid and released under the MIT License. The software was tested with Python 3.10+, PyTorch 2.0+, pandas 2.0+, NumPy 1.23+, scikit-learn 1.3+, and Matplotlib 3.7+.
