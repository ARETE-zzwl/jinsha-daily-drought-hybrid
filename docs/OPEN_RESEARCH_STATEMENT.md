# Open Research Statement for WRR

Use this text in the manuscript's Open Research section.

## Data Availability Statement

The processed daily station data, station metadata, manuscript-derived table and figure data, full prediction tables, trained model checkpoints, and station-matched CMIP6 auxiliary training sequences are archived in the Zenodo reproducibility package by Zhu et al. (2026): https://doi.org/10.5281/zenodo.22232487. The archive contains daily meteorological forcing, reference evapotranspiration, radiation variables, streamflow/runoff, and station metadata for the eight-station Jinsha River Basin main experiment and the 16-station Upper Yellow River external validation. The CMIP6 station sequences are used only for training-stage auxiliary regularization in the Jinsha experiment and are not used as validation/test predictors. The custom 30-day and 90-day standardized water-balance drought indices and flash-drought early-risk labels are generated by the released code using training-period standardization to avoid temporal leakage. The processed station observations may be publicly redistributed; processed data and derived manuscript data are released under CC BY 4.0. The original observation-driven station data were provided by the National Meteorological Information Center (NMIC). The auxiliary climate sequences were derived from the NEX-GDDP-CMIP6 daily downscaled climate-model dataset, and station elevation information was derived from Copernicus DEM 30 m products.

## Software Availability Statement

Version **1.1.0-wrr-revision** of the Python code used for data preprocessing, target construction, model training, baseline comparison, recursive forecasting, external-basin evaluation, ablation summaries, and manuscript figure/table data generation is archived in Zenodo by Zhu et al. (2026): https://doi.org/10.5281/zenodo.22232487. The code is developed openly at https://github.com/ARETE-zzwl/jinsha-daily-drought-hybrid and released under the MIT License. The software was tested with Python 3.10+, PyTorch 2.0+, pandas 2.0+, NumPy 1.23+, scikit-learn 1.3+, and Matplotlib 3.7+.
